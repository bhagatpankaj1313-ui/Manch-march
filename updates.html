Updates

Development history for Manch March, newest first. The current release is v260.

v260 — New app icon

Fresh launcher icon: the red-flag march artwork. The game itself is unchanged from v259.

v259 — Launch build

Stages unlock one by one from level 1. Every player starts fresh: zero coins, no items, no unlocked stages. Police and co-op coin earnings halved so unlocking stays earned. Default graphics set to full quality (ultra particles, ultra bloom, threat outlines on).

v258 — Co-op difficulty settled

Police co-op protesters at 1.8× vs solo, still growing over time to a 2.7× maximum. Netaji keeps his co-op health bonus (65). Flash shells detain 4 per shell in co-op.

v257 — Easier co-op, tougher Netaji

Co-op base difficulty 1.3× with the time ramp kept, and Netaji's health raised by 40 in co-op only (65 vs 25 solo).

v256 — Difficulty grows over time

Co-op difficulty now ramps +5% per 90-second tier, capped at 1.5×, on top of the flat multiplier.

v255 / v254 — Co-op tuning passes

Co-op protesters at 2× (v255) after 4× proved too much (v254).

v253 — Character animation pass

Smoother character motion: spring-damped sway for scarves, capes, placards, caps and hair, with eased transitions across all character drawing.

v252 — Interface pass

Minimalist dark-slate glass interface across menus, shop and HUD.

v251 — Performance pass

Faster rendering: compositor-transform joysticks, reused scratch objects, and once-per-frame outline colours. No gameplay change.

v250 and earlier

Feature cleanups (campus cup, model gallery and newspaper removed), minimap parity, end-screen fixes, and the title-screen readability fix.
